# Branding & Interface Directive

## Color Palette
- **Deep Blue**: Primary background/navigation.
- **White**: Text, high contrast elements.
- **Precision-Cyan**: Accents, buttons, highlights.

## UI Layout
- **Sidebar**:
  - Lead Manager
  - Agent Workshop (Upgrades)
  - Email Automation
  - Settings
- **Main View**:
  - "God-Mode" map view showing leads found by The Scout.

## Theme
- Sleek, professional, "Aesthetic".
- Tailwind CSS configuration must reflect this.
